賽事淨勝球率

-

公式：淨勝球 / 場次
意義：平均每場比賽的淨勝球數據。標準化各選手每場比賽平均「壓倒對手」或「落後對手」的球數差距。

3. 進階效益分析

得失球比

-

公式：進球 / 失球
意義：比單純的「淨勝球」更能客觀呈現攻防平衡度。例如進10丟5與進2丟1比值皆為2.0；若小於1.0則屬於防守負債。

進球轉化積分率

-

公式：積分 / 進球
意義：平均一顆進球賺多少積分。數值越高，代表擅長踢出 1:0 等關鍵勝場，不浪費進球。

防守容錯率

-

公式：失球 / 積分
意義：每拿到1分積分，平均需要承受多少次失球。衡量球隊在失球狀態下的抗壓得分能力。
